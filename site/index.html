Start the conversation here.

The “Comments on…” panel below this heading uses the same component you can install on your site. Sign in with your Synaptiq Google account to read, post, and reply. Public documentation remains readable without signing in.

Something for the maintainers?

Open Send feedback at the bottom of the screen. Feedback goes to the private inbox, not the discussion. You’ll receive a reference when it is saved.

The initial participation policy is Synaptiq Google accounts only. Public reading is open to everyone. This first version supports immutable comments and replies; editing and moderation are not available yet.

Bring the conversation to your publication.

Use the Hugo integration or add the browser marker to an existing static page. Cloudflare Worker and D1 provide the first backend. Infrastructure and application releases have separate, explicit deployment steps.
